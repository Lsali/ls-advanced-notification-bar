A lightweight, fully customizable, and responsive notification bar plugin for WordPress.

== Description ==

LS Advanced Notification Bar allows you to display eye-catching promotional messages, announcements, or custom call-to-action buttons across your site or on specific pages.

Built with PHP 8.2 standards and WordPress best practices, it provides maximum performance without slowing down your website.

=== Key Features ===

* **Flexible Positioning:** Display the bar at the top or fixed at the bottom of the screen.
* **Custom Call-to-Action (CTA):** Easily add a action button with custom text, destination URL, and inline CSS styling.
* **Access Control:** Choose to show notifications to all users, guests only (logged-out), or registered members only (logged-in).
* **Page/Post Exclusion:** Exclude specific posts or pages using an interactive multi-select control (Select2).
* **Expiry Date Schedule:** Set an automatic expiration date for time-sensitive promotions or deals.
* **Color Customization:** Full control over background color, text color, and bottom border color using native WordPress color pickers.
* **Display Delay:** Set a custom delay in milliseconds before the bar appears to visitors.
* **Dismissible Option:** Allow visitors to close the notification bar with a close button (X).
* **Clean Code & Performance:** Lightweight CSS/JS footprint, secure sanitization, and full internationalization (i18n) support.

== Settings & Configuration ==

Once activated, you can configure all settings from the WordPress Admin Dashboard:

1. Go to **Settings** -> **LS Notification Bar**.
2. **Enable/Disable:** Check the "Enabled" box to activate the notification bar on your site.
3. **Customize Content:** Enter your notification text, button label, and destination URL.
4. **Style & Visibility:** Set colors, font size, positioning (top/bottom), display delay, and exclude specific pages/posts.
5. Click **Save Changes** to publish your bar live on the frontend.

== Installation ==

1. Upload the `ls-advanced-notification-bar` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Navigate to **Settings** -> **LS Notification Bar** to configure your options.
